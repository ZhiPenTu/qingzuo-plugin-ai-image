图像 API 配置

复用已有外部代理，或使用插件专用官方密钥。

返回 AI 批图

外部代理 · 共享连接

使用轻作「AI 设置 → 代理连接」中已保存的连接和配置，不必重复填写 Google / OpenAI 密钥。支持 GPT Image 编辑接口、Gemini / Nano Banana 原生接口以及已声明的 OpenAI 兼容图片模型。

返回批图后选择「外部代理」即可使用。

这里只读取模型列表，不生成图片。服务必须实际拥有图像编辑权限；外部代理的路由与参数在其原有管理端配置。

官方 API · 插件专用密钥

仅选择「官方 API」来源时才需要配置。保存后不回显密钥，与代理账户互不替代。

图片仅在确认执行后上传，可能产生费用或消耗账户额度。

想配置 AI 助手？

点击轻作左侧「AI 设置」，选择支持工具调用的默认文本模型。批图中选择图片模型不会更改助手型号。

助手只生成方案，未经确认不会发起图像请求。

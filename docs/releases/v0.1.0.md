# AI 批图 v0.1.0

- 批量导入原图，统一提示词及逐图覆盖；保存提示词模板、单图试运行、批量执行、停止及失败项重试。
- 默认复用轻作已配置的外部代理图片模型和配置，也可选择 Google / OpenAI 官方图像 API。模型从实际代理目录发现，不静默降级。
- Harness AI 助手可优化逐图方案；确认来源、型号和提示词并授权输出目录后才生成。
- 并发 1–4，完成一张保存一张，不覆盖原图。关闭插件窗口仍后台处理；保存失败不重新调用模型，退出后支持手动恢复未开始项。
- 凭据保留在宿主，任务与目录隔离。状态未知的中断请求不会自动重发。

需要轻作 0.3.0 / 插件 API 1.2.0（macOS 15+ Apple Silicon、Windows 10+ x64）。双平台固定响应验收不产生付费请求；真实图像编辑权限、效果、费用和 OAuth 全流程尚需实际账户验收。市场签名和上架独立于本 Release。

# AI 批图

轻作独立插件 `official.ai-image`，版本 0.1.2，需要轻作 0.3.0 / 插件 API 1.2。

导入 `release/official.ai-image-0.1.2-darwin-arm64.ecplugin` 后，可直接复用轻作「AI 设置 → 代理连接」配置的外部代理。在插件中选择「外部代理」来源并刷新图片模型，无需再填官方密钥；也可主动选择「官方 API」来源，使用插件隔离的 Google / OpenAI Key。对话与方案规划统一使用轻作底座「AI 对话」，插件本身不内置对话 AI。

批量选择 PNG、JPEG、WebP，设置统一提示词及逐图覆盖，点击准备方案；确认方案和输出目录后执行。可先单图试运行。关闭插件仍继续处理，退出应用停止请求。已保存结果保留；恢复时重新授权输出目录，状态未知的请求不会自动重发。保存失败保留图片并可重新保存。

`npm ci --ignore-scripts && npm test && npm run pack` 构建插件。SDK 1.2.0 的固定 tarball 随项目保存，发布时对照 SDK Release 的 SHA-256 验证，运行插件无需 Node/npm。

代理目录按真实 `/v1/models` 返回发现 GPT Image、Gemini / Nano Banana 和 `type: openai-image` 的兼容别名，不硬编码代理中不存在的型号。GPT Image 使用 `/v1/images/edits`，Gemini 使用 `/v1beta/models/{id}:generateContent`；兼容模型需要在代理端配置 `image: true`。目录存在不代表账户有编辑权限，服务拒绝时显示错误，不换型号、不自动重试。只接受内联图片结果，URL-only 响应不进行额外下载。轻作不重发生成；外部代理自身的重试和额度策略由其管理端设置。
# 配置入口

轻作侧栏「AI 设置」→「配置图像 API」打开独立插件配置页。插件顶部同名按钮打开配置弹窗，保留图片队列和提示词。代理访问密钥及 OAuth 令牌由轻作管理，插件不接收密钥、不直接访问本机代理。官方模式保留专用 Key，保存后不回显；空白不能覆盖已有密钥；清除需要确认。批次冻结来源、型号和参数，改变代理地址/模式后需重新准备；已有生成结果仍能重新保存。旧底座会提示升级。

## 发布与验收

标签 `v0.1.0` 触发 macOS arm64 / Windows x64 独立构建。仓库变量 `QINGZUO_HOST_RUN_ID` 指向轻作 v0.3.0 成功的正式发布构建，发布脚本核对其提交与正式标签后下载固定制品，在源码目录外运行插件黄金路径。自动化只使用固定响应，包含官方 / 代理图片编辑、11 张结果保存，不产生付费请求。

插件 Release 发布后由 `ZhiPenTu/qingzuo-market` 验证原始制品 SHA-256、清单和发布者，使用既有 Ed25519 密钥签名，再经目录 PR 上架。图像模型存在不代表实际账户具备权限；真实账户图像效果、费用 / 额度及 OAuth 全流程仍需用户验收。

上架后手动运行发布工作流的 `validation: market`，在两个系统验证公开签名市场安装、启动插件及底座字节未被修改，不配置真实账户、不生成图片。
